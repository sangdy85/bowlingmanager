경기 방식
- 경기 60초 고정. 출발 준비 3초와 결과 표시 대기 1초는 별도다.
- 아이템은 참가자에게 자동으로 무작위 발동한다. 클릭/카메라 조작으로 승부를 바꾸지 않는다.
- 자석: 앞 참가자에게 끌려가는 추가 이동력, 3초.
- 부스터: 현재 이동 속도 1.5배, 3초.
- 스프링: 뒤로 튕기는 위치 변화와 점프 연출.
- 미사일: 바로 앞 순위에 발사, 0.6초 뒤 피격/밀림.
- 1위 미사일: 발사 시점의 선두에게 발사. 자신이 선두라면 자신을 공격하지 않는다.
- 바나나: 2초 미끄러짐/감속.
- 폭주: 3초 가속과 충돌 상대 밀어내기/튕김.
- 물폭탄: 앞쪽 범위 폭발 후 해당 범위의 상대를 3초 감금.
- 망치: 앞에 설치, 닿은 상대 4초 기절.
- 오르막 감속과 내리막 가속은 모델과 화면이 같은 코스 정의를 사용한다.
- 마지막 6초는 결승 스퍼트이며, 경사에 따른 속도 차이를 유지한다.

구현 설명
경기 모델은 100ms 고정 간격으로 미리 시뮬레이션한 경로를 재생한다. 프레임 수·탭 표시·화면 크기가 결과에 영향을 주지 않는다.
익명 경기 슬롯을 먼저 계산하고, 참가자는 기존 Web Crypto 무편향 섞기로 슬롯에 무작위 배정한다. 이름/등록 순서로 유리한 슬롯을 지정하지 않는다.
아이템의 가속·기절·밀림·범위 공격은 실제 이동 거리와 순위에 영향을 준다. 아이템을 끄면 같은 테스트 시드의 최종 순위가 달라지는 것을 검증했다.
새 아이템 발동은 49.5초까지 허용하고 설치 망치는 50초까지 판정하여, 가장 긴 기절도 54초까지 끝나도록 한다.
54초의 실제 누적 거리(동률이면 현재 속도)를 기준으로 결승 순서를 정한다. 마지막 6초는 그 순서를 유지하며 경사별 이동 비용에 맞춰 결승선을 통과하는 스퍼트다. 목표 인원 마지막 당첨자가 경기 60초에 도착한다.
따라서 마지막 6초에는 새로운 아이템 공격이 발생하지 않는다. 마지막 순간에 임의로 당첨자를 교체하는 로직은 없다.
기존 1~20명 설정, 부족한 후보 수 제한, 입상자/대기자/기당첨자 제외, 등록 ID 구분, 중복 완료 방지, 저장 후 잠금을 유지한다.
winners/winnerCount/excludeRankers/isFinalized 저장 JSON 및 기존 저장 Server Action을 변경하지 않았다.

화면
굽은 코스, 두 언덕, 강과 나무 다리, 마을/나무, 아이템 상자, 시작/결승 아치와 미니맵을 직접 Canvas로 그렸다.
전체 맵/따라보기, 참가자 추적, 경사 상태, 아이템 중계, 현재 효과 배지, 9종 아이템 안내를 추가했다.
참고 이미지의 일반적인 맵 구성을 참고했으며 외부 사이트 코드/이미지를 복사하거나 임베드하지 않았다.
움직임 최소화 설정에서도 60초 경기 시간은 유지하며 전체 맵 카메라와 낮은 화면 갱신 빈도를 사용한다.
새 의존성이나 외부 이미지 다운로드는 없다.
