확인한 기존 구조
- User.managedCenters <-> BowlingCenter.managers: 여러 사용자와 여러 볼링장을 연결하는 기존 관계.

남은 운영 설계
- 최고 관리자가 계정 화면에서 센터를 직접 지정/해제하는 기능은 추가하지 않음. 기존 인증 코드 방식 유지.
- CENTER_ADMIN은 UI에서 추가 인증 코드 입력을 숨기므로 기존 모델의 복수 센터 연결 능력과 등록 UI 범위가 다름.
- 일부 센터 기능은 owner 또는 managers를 인정하지만 verifyCenterAdmin/센터 회원 관리/대회 신규 화면은 managers만 인정.
- updateUserRole로 일반 역할로 바꿔도 기존 managedCenters는 남음. 관계만 검사하는 기능의 권한은 역할 변경만으로 해제되지 않을 수 있음.
- leaveCenter는 모든 managedCenters를 해제하는 기존 동작. 센터별 개별 해제 없음.
위 항목은 권한·Server Action 동작 변경을 수반하므로 이번 표시 개선에 임의 포함하지 않음.
