2. 기능 범위
Client ID/Secret 없이 공식 BAND 공유 URL을 열고, 관리자가 BAND에서 최종 게시한다.
상주리그는 선택 주차의 기존 4종 결과표 PNG 생성/다운로드를 재사용한다.
챔프전·이벤트전은 참가자/레인배정/최종 결과 공지와 전체 결과 이미지 생성을 지원한다.
기본 문구는 대회명·주차/회차·항목으로 구성한다.
대회 설정에서 사진 위/아래 기본 문구를 저장하고, 공유 미리보기에서 이번 문구를 수정할 수 있다.
공식 웹 공유에는 PNG를 직접 첨부할 수 없어 저장 후 수동 첨부 안내를 제공한다.
지원 기기는 파일+문구 네이티브 공유를 제공하며, 미지원/실패 시 다운로드·복사·웹 공유를 제공한다.
사진과 문구의 실제 배치는 BAND에서 관리자가 확인한다.
팝업 차단 시 새 탭 링크를 제공한다. 긴 URL은 본문 전체 복사 후 빈 공유 화면으로 안내한다.
기존 OAuth/암호화/자동 게시/게시 이력 코드를 보존했다.
공유 화면 열기나 OS 공유 완료를 BAND 게시 성공으로 기록하지 않는다.
테스트 전용 QA layout의 inline body style을 CSS로 옮겨 hydration 불일치도 수정했다.
상세 구현·파일별 변경 이유는 band-official-share-20261026.txt를 참고한다.
