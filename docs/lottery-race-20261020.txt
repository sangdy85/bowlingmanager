동작
챔프전/이벤트전의 기존 행운권 추첨 탭에만 적용한다.
추첨 인원 1~20명, 경기 시간 12/20/30초 + 출발 카운트다운 3초.
한 경기에서 남은 목표 인원만큼 도착 순서대로 당첨. 후보가 부족하면 후보 수까지만 추첨한다.
참가 등록 ID로 후보/당첨자를 구분하며 이름이 같아도 임의로 합치지 않는다.
기존 입상자 제외, 대기자 제외, 기당첨자 제외 및 결과 저장 후 잠금을 유지한다.
출발 전에는 참가 번호 순으로 표시하여 최종 당첨 순서를 미리 드러내지 않는다.
추첨 순서는 프레임 속도·화면 크기·따라보기·레이스 시간과 독립적이다.
백그라운드 탭에서 애니메이션이 지연되어도 동일 결과로 완료하고 이중 콜백으로 당첨자를 중복 추가하지 않는다.
화면 이동 시 진행 타이머를 해제한다. 저장 전 결과의 새로고침/이동 시 소멸 규칙은 그대로다.
기존 winners/winnerCount/excludeRankers/isFinalized JSON 및 저장 Server Action을 유지한다.
외부 의존성 추가 없음. 기존 LotteryWheel/공유 CSS는 다른 작업과의 불필요한 충돌을 피하기 위해 삭제하지 않았다.
