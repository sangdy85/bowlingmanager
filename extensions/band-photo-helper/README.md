# BowlingManager BAND 사진 전달

PC Chrome·Edge용 설치형 보조 확장프로그램입니다. BAND 공식 공유 링크의 사진 첨부 기능이 아닙니다.

볼링매니저에서 준비한 PNG를 저장·파일 선택 과정 없이 BAND 일반 글쓰기 화면의 사진 입력란에 전달합니다. BAND 선택, 글쓰기 창 열기, 최종 게시 확인은 관리자가 합니다. 확장프로그램은 게시 버튼을 누르지 않습니다.

## 처음 한 번 설치

1. 설치 ZIP을 폴더에 압축 해제합니다. `manifest.json`이 들어 있는 폴더를 사용합니다.
2. Chrome에서는 주소창에 `chrome://extensions/`, Edge에서는 `edge://extensions/`를 입력합니다.
3. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 1번 폴더를 선택합니다. 확장프로그램 목록에서 **BowlingManager BAND 사진 전달**을 확인하고 도구 모음에 고정합니다.

Chrome 웹 스토어 배포본은 아닙니다. 설치는 사용자가 직접 확인해야 합니다. 새 파일 버전으로 교체하면 확장프로그램 목록의 새로고침 버튼을 눌러주세요.

0.2.0부터 볼링매니저 공유 화면의 **PC BAND에 사진 전달** 버튼과 연결합니다. 기존 0.1.0 설치 폴더를 업데이트한 경우 확장프로그램 목록에서 새로고침하고 볼링매니저 페이지도 새로고침해주세요. Chrome이 공식 볼링매니저 사이트 접근 확인을 요청하면 내용을 직접 확인해야 합니다.

0.2.2는 BAND의 사진 업로드 → 「첨부하기」 → 편집기 사진 생성 순서를 기다린 뒤 사진 위·아래 문구를 각각 배치합니다. 이전 버전은 사진 선택창이 끝나기 전에 글을 넣어 사진이 위로 올라가는 문제가 있었습니다. 기존에 작성한 글과 서식은 보존하며 사진 위로 정리합니다. 새 파일로 교체하고 확장프로그램 목록에서 새로고침한 뒤, 이전 첨부 작성창 대신 새 글쓰기 창을 사용해주세요.

## 사진 전달

0.2.4는 사이트 안에서 대회·회차 페이지로 이동한 뒤 사진을 전달할 때 초기 문서 주소와 현재 주소가 달라 요청이 무응답으로 끝나던 검사를 수정합니다. 같은 공식 도메인의 최상위 확장프로그램 스크립트만 허용하며 다른 도메인·프레임·임의 페이지 메시지는 계속 차단합니다. 주소 검증 실패와 확장프로그램 업데이트 후 필요한 새로고침도 구체적으로 안내합니다. 새 파일로 교체한 뒤 확장프로그램과 볼링매니저 페이지를 모두 새로고침해주세요.

0.2.3은 사진 전달 전에 커서를 글 끝으로 옮기고 편집기에 위치를 알린 뒤, 그 위치가 유지되는지 확인합니다. 첨부 완료 후에도 커서를 끝에 두며, 기존 Home 키 알림은 제거했습니다. 이는 이후 사진을 추가할 때 글 앞에 삽입되는 문제를 줄이기 위한 변경입니다. 커서가 다시 앞으로 이동하면 경고하고 자동 처리를 멈춥니다.

1. 확장프로그램을 설치한 같은 브라우저에서 볼링매니저와 BAND에 직접 로그인합니다.
2. 볼링매니저의 **BAND 공식 공유하기** 미리보기를 열고 사진을 준비합니다. 상주리그는 **선택 주차 결과표 4종 준비**를 누릅니다.
3. 선수 이름·팀·기록의 공유 범위 확인을 체크합니다. 사진 파일을 저장하거나 수동 첨부 확인을 체크할 필요는 없습니다.
4. 공유 화면 하단의 **PC BAND에 사진 전달**을 누릅니다. **확장프로그램 연결됨**이 표시되며, 사진과 문구를 가져오고 일반 BAND 웹사이트가 열립니다. 브라우저 상단 확장프로그램의 **사진 가져오고 BAND 열기**도 계속 사용할 수 있습니다.
5. BAND에서 대상 밴드를 선택한 뒤 **글쓰기**로 새 작성창을 엽니다. 공식 공유 팝업에는 사진 입력란이 없으므로 일반 글쓰기 창을 사용합니다.
6. 확장프로그램을 다시 누르고 **이 글쓰기 화면 확인** → 밴드 이름 확인 → **확인한 글쓰기 창에 사진 첨부**를 누릅니다.
7. 사진 업로드 후 확장프로그램이 사진 선택창의 **첨부하기**만 한 번 누릅니다. 편집기에 사진이 생긴 다음 위·아래 문구를 배치하고 순서를 검사합니다. 확인 메시지와 실제 미리보기를 검토한 뒤 **게시**는 직접 누릅니다.

빈 글쓰기 창에는 준비한 사진 위·아래 문구를 각 위치에 넣습니다. 이미 작성한 문구가 있으면 덮어쓰지 않고 기존 글을 사진 위에 보존합니다. 문구가 들어가지 않으면 볼링매니저의 공지 문구 복사를 사용해주세요.

## 권한과 임시 자료

- `activeTab`: 확장프로그램 아이콘을 누른 현재 탭에만 임시 접근합니다. 모든 사이트 상시 접근 권한은 요청하지 않습니다.
- `scripting`: 해당 탭의 볼링매니저 미리보기 읽기 및 BAND 글쓰기 사진 입력에 사용합니다.
- `alarms`: 준비한 사진을 20분 후 삭제하는 용도입니다.
- 0.2.0의 사이트 연결 스크립트는 `https://bowlingmanager.co.kr/*`와 `https://www.bowlingmanager.co.kr/*` 두 곳에만 실행됩니다. 관리자가 공유 버튼을 직접 클릭했을 때만 준비된 미리보기를 읽습니다. 페이지가 보낸 임의 자료나 프로그램으로 만든 클릭은 받지 않습니다. 다른 사이트나 BAND에는 상시 스크립트를 넣지 않습니다.
- 공유 미리보기 읽기 함수 파일만 두 공식 사이트에 공개하며 쿠키·토큰·준비 사진은 공개하지 않습니다. 서비스 워커는 같은 확장프로그램의 공식 사이트 최상위 탭에서 온 가져오기 요청만 받고, 그 출처와 사진을 다시 검증합니다.
- 자료는 확장프로그램의 이 PC 임시 저장소에 보관합니다. 전달 요청 후·20분 만료 후·브라우저 재시작 시 삭제합니다. 브라우저가 꺼져 있는 동안에는 삭제 작업이 실행되지 않으며 다음 시작 시 지웁니다. 준비된 사진 지우기로 즉시 지울 수도 있습니다.
- 쿠키·비밀번호·인증 토큰·다른 게시글·채팅을 읽지 않습니다. 별도 서버로 전송하지 않습니다. 사진 업로드는 BAND의 정상 사진 입력 이벤트를 통해 BAND 자체 코드가 처리합니다.
- BAND의 비공식 API, 자동 로그인, 자동 최종 게시를 사용하지 않습니다.

## 제한과 오류 처리

- 볼링매니저 공식 HTTPS 도메인에서 가져온 PNG만 허용합니다. 1~20개, 인코딩 기준 총 36MB 이하입니다. 넘으면 자르지 않고 중단합니다.
- 다른 밴드로 이동했거나 확인한 작성창이 바뀌면 다시 확인해야 합니다.
- 채팅·프로필·글 수정·공식 공유 팝업에는 전달하지 않습니다. 기존 사진이 있는 작성창이나 한 번 전달한 작성창은 중복 첨부를 막습니다.
- BAND UI가 변경되어 정확한 사진 입력란을 찾지 못하면 중단합니다. 임의의 업로드 입력란을 골라 사용하지 않습니다.
- 업로드/첨부는 최대 30초 기다립니다. 실패하거나 문구 순서를 확인하지 못하면 경고하며, 이미 보낸 사진을 중복 전송하지 않습니다. 이때 작성창을 직접 확인하세요. 게시 성공 상태는 기록하지 않습니다.

## 확인한 범위

2026-10-26 실제 BAND에서 테스트 PNG 4개를 정상 파일 선택 → 사진 올리기 → 첨부하기로 올린 다음 문구를 넣어, 문구가 사진 위에 유지되는 것을 확인했습니다. 게시 버튼은 누르지 않았습니다. 이 과정에서 기존 버전이 빠뜨린 별도 첨부 단계를 확인했습니다.

실제 Chromium의 2단계 첨부 모형에서 동일한 확장프로그램 함수를 실행해 위 문구 → 사진 4개 → 아래 문구, 기존 서식 글 보존, 대상 변경 중단 및 중복 전송 방지를 검사합니다. 이는 설치된 확장프로그램과 실제 BAND 업로드를 연결한 종단간 테스트와는 구분합니다. 실제 설치 브라우저에서 업데이트 후 최종 확인은 남아 있습니다. 실제 게시를 자동 실행하지 않습니다.
